# mkdox-material-derived

Docker build for mkdocs / material with some essential plugins

* start from [squidfunk/mkdocs-material](https://hub.docker.com/r/squidfunk/mkdocs-material)
* add following `mkdocs` plugins:
    * [Guts/mkdocs-rss-plugin](https://github.com/Guts/mkdocs-rss-plugin)
    * [blueswen/mkdocs-glightbox](https://github.com/blueswen/mkdocs-glightbox)
    * [byrnereese/mkdocs-minify-plugin](https://github.com/byrnereese/mkdocs-minify-plugin)
    * [cmacmackin/markdown-include](https://github.com/cmacmackin/markdown-include)
    * [lukasgeiter/mkdocs-awesome-pages-plugin](https://github.com/lukasgeiter/mkdocs-awesome-pages-plugin)
    * [mondeja/mkdocs-include-markdown-plugin](https://github.com/mondeja/mkdocs-include-markdown-plugin)
    * [timvink/mkdocs-git-revision-date-localized-plugin](https://github.com/timvink/mkdocs-git-revision-date-localized-plugin)
    * [zachhannum/mkdocs-autolinks-plugin](https://github.com/zachhannum/mkdocs-autolinks-plugin)

Used by [pforret/mkdox](https://github.com/pforret/mkdox)
